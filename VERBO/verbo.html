COMO JOGAR

  • O objetivo é adivinhar a palavra oculta usando o teclado.
  • Pode ser uma palavra de 5, 6 ou 7 letras.
  • Se precisar de ajuda, clique em PEDIR DICA para ler uma charada.
  • Após digitar as letras, clique no botão VERIFICAR para testar sua resposta.
  • As cores das letras vão mudar para mostrar o quão perto você está:

    🟩 Verde: Letra certa, no lugar certo.
    🟨 Amarelo: A letra existe na palavra, mas está no lugar errado.
    ⬛ Escuro: A letra não existe na palavra.
